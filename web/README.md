# বাঘ-ছাগল: web game

Play Bagh-Chagol and Four in a Row in the browser against the AlphaZero-style agents
trained in the parent project. The home screen lets you pick a game; `#bagh` and
`#fourrow` in the address open one directly. Four in a Row is dressed in stock art,
icons, cursor, font and sounds from the [KAPLAY crew](https://kaplayjs.com/crew). Built with [kaplay](https://kaplayjs.com); the network runs in the
browser with onnxruntime-web.

```sh
bun install
bun run dev      # dev server at http://localhost:3001
bun run test     # check the TypeScript rules against Python
bun run build    # static site in dist/ (works from any folder, e.g. GitHub Pages)
```

## Publishing (SEO and link previews)

Build with the address the site will live at, so link previews and search engines get
absolute URLs (canonical link, `og:url`, `og:image`, `robots.txt`, `sitemap.xml`):

```sh
SITE_URL=https://you.github.io/bagh-chagol/ bun run build
```

The icons and the share image (`public/og-image.png`, 1200x630, a screenshot of the
menu) are made by `bun scripts/make-share-images.mjs` while `bun run preview --port 4173`
is running. Re-run it after visual changes to the menu.

After training a network in the parent project, export it:

```sh
cd ..
uv run --group web export_web.py            # everything
uv run --group web export_web.py fourrow    # or just one game / map
```

Until a game has a trained network, its AI plays by search with quick random playouts.

## Layout

- `src/rules.ts`: Bagh-Chagol rules (port of `bagh/game.py`)
- `src/fourrow/`: Four in a Row: rules (port of `fourrow/game.py`), playout AI, art, menu and game scenes
- `src/ai/`: game-independent MCTS + network evaluation, run in a Web Worker
- `src/art/`: board, scenery and piece artwork (kaplay drawing); `crew.ts` loads the KAPLAY crew assets
- `src/scenes/`: the home screen, and the Bagh-Chagol menu and game
- `public/maps/`, `public/fourrow/`: exported boards and networks (generated by `export_web.py`)
- `public/title.png`: the Bengali title, made by `bun scripts/make-title.mjs`
- `tests/`: rules and network checks against Python fixtures
